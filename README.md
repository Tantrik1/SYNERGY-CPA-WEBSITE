# Synergy CPA Professional Corporation - Web Application

A modern, high-performance web application for **Synergy CPA Professional Corporation** ([thesynergycpa.com](https://thesynergycpa.com/)), a registered CPA firm based in Greater Toronto (Scarborough, ON).

---

## 🚀 Key Features

* **Financial Clarity & Cash Runway Simulator**: Live interactive client discovery benchmark widget.
* **Integrated Services Suite**: Interactive modal deep-dives across all 8 practice areas (Accounting, Tax, Payroll, Fractional CFO, Business Advisory, Cash Flow, Budgeting, and Internal Controls).
* **100+ Years Combined Leadership**: Profiles, credentials, and bios for Santosh Lamichhane, Sechan Devkota, and Hari Lamsal.
* **Coffee & Clarity Consultation Booking**: Interactive 30-minute strategic intake workflows.
* **Insights & Articles Reader**: Educational knowledge hub for Canadian business owners, founders, and newcomers.
* **Modern Design System**: Google Fonts (Plus Jakarta Sans, Inter, JetBrains Mono), glassmorphic components, responsive grid system, and subtle micro-animations.

## 💻 Local Development

Run a lightweight local HTTP server:

```bash
# Python
python3 -m http.server 3000

# or Node.js / NPX
npx serve .
```

Open `http://localhost:3000` in your browser.
